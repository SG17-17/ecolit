Unidimensional measurement model for ESI (6 items). *Purely theoretical.*

```{r}
#| label: setup-cfa-esi
#| include: false

source("R/helpers.R")
df <- readRDS("data/cleaned_data.rds")
```

```{r}
#| label: cfa-esi
model_esi <- "
  ESI =~ ESI_1 + ESI_2 + ESI_3 + ESI_4 + ESI_5 + ESI_6 
"
fit_esi <- cfa(model_esi, data = df, std.lv = TRUE, estimator = "MLR")
summary(fit_esi, fit.measures = TRUE, standardized = TRUE)

# Save results for summary page
saveRDS(fit_esi, "data/fit_esi.rds")
```
